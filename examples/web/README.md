# Web 用户目录

此示例使用 Vue 页面、共享 `UserService` 和 Fetch 适配器完成用户搜索与详情读取。业务模型来自 `@reqvia/example-domain`，页面负责查询代次、加载与错误状态，以及视图退出时的取消。

在仓库根目录执行：

```sh
vp run -F @reqvia/example-web dev
```

开发任务先构建工作区依赖，再启动页面与本地示例接口。输入姓名或角色后搜索，选择成员查看详情；「取消」结束当前查询，「离开目录」卸载视图并释放尚未完成的调用。

验证命令：

```sh
vp run -F @reqvia/example-web test
vp run -F @reqvia/example-web verify
```

`verify` 先构建，再通过本机 Chrome 或 Chromium 操作生产页面。可用 `CHROME_BIN` 指定浏览器路径。验收同时检查页面结果与本地服务观察到的连接取消，覆盖列表、详情、空状态、领域校验错误、HTTP 失败、快速切换查询、手动取消、视图卸载和页面导航。视图卸载通过「离开目录」按钮触发，页面导航通过页头链接触发。

本地后端保留几个可复现情形：`slow` 和 `fast` 返回不同用户并产生不同延迟，`invalid` 返回不符合用户模型的数据，`error` 返回 HTTP 失败，`hang` 持续等待。它们只用于本地演示与验收，不属于 Service 的业务约定。

状态单元测试另用不响应取消的服务替身返回迟到成功和失败，确保查询代次在结果提交时仍然生效。相关逻辑保留在应用层，示例没有给 Reqvia 增加查询缓存或并发策略 API。
